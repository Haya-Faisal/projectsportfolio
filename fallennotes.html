Fallen Notes

Github Project

Impact

An interactive, physics-based Newton's cradle where clay pots swing instead of steel balls — every collision launches a synthesized musical note that falls, bounces, and piles up at the bottom of the screen, draggable by mouse or touch.

Tools

Matter.js, poly-decomp, HTML5 Canvas, Web Audio API, DeviceOrientation API

Timeline

July 2026

Features

Concave Pot-Shaped Physics Bodies

  • Custom Vertex Outline: Each pot is a hand-traced concave polygon (narrow neck, wide belly) built with Bodies.fromVertices.
  • Parent-Body Resolution: Collision events return individual sub-parts, not the whole pot — all collision logic resolves to body.parent to work with the correct pot as a whole.

Collision-Triggered Musical Notes

  • Real Physics Note Bodies: Hard pot-to-pot collisions (measured by relative velocity) spawn small circular note bodies that fall, tumble, and bounce under real gravity.
  • Collision Filtering: Notes are set to ignore the pots entirely (so a falling note can't disturb the cradle's swing) while still colliding with the ground and each other.
  • Boundary Walls: Invisible static walls on the left, right, and top edges keep notes from drifting off-screen.
  • Ground Accumulation: A static floor lets notes pile up and rest realistically at the bottom of the screen.

Draggable Notes and Pots

  • MouseConstraint Interaction: Both pots and settled/falling notes can be grabbed and dragged with mouse or touch.
  • Collision Filter Compatibility: Note filters were tuned to still be visible to Matter's mouse-picking logic despite otherwise ignoring pots physically.

Synthesized Sound Design

  • Web Audio API Tone Generator: No sound files — tones are synthesized live with oscillators and a quick-attack, exponential-decay envelope.
  • Pentatonic Scale: Every emerge/land/drag sound randomly picks a note from a pentatonic scale, so overlapping sounds always stay musically consistent.
  • Distinct Triggers: Separate sounds for a note emerging from a collision, landing on the ground, and being picked up by the mouse.

Device Tilt (Gyroscope) Support

  • Tilt-Driven Gravity: Device orientation (gamma/beta) remaps engine.world.gravity, so loose notes roll toward whichever way the device tilts — like a ball-in-maze toy.
  • Pots Unaffected: Pots use inertia: Infinity and hang from fixed string anchors, so they keep swinging normally regardless of tilt — only loose notes respond.

Responsive, Always-Centered Layout

  • Full-Viewport Canvas: Canvas sizes to window.innerWidth/innerHeight and re-centers the cradle and ground on resize.
  • Responsive Sizing: Pot and note sizes scale relative to screen width (clamped min/max) so they stay proportionate on both small phones and wide desktop screens.

Technical Stack

Performance & Robustness Features

  • Note Cap: A maximum note count removes the oldest note once exceeded, preventing unbounded body growth.
  • Collision Category Isolation: Separate collision categories for notes vs. ground keep physics interactions cheap and predictable.

Technical Implementation

Concave Pot Body Construction

function potVertices(size) {
  var points = [
    { x: 0.45, y: 0 }, { x: 0.55, y: 0.05 }, { x: 0.5, y: 0.1 },
    { x: 0.35, y: 0.18 }, { x: 0.4, y: 0.28 }, { x: 0.6, y: 0.4 },
    // ...traces the pot's neck-in, belly-out silhouette
  ];
  return points.map(function (p) {
    return { x: p.x * size, y: p.y * size };
  });
}

var pot = Bodies.fromVertices(x, y, [potVertices(size)], {
  inertia: Infinity,
  restitution: 1,
  friction: 0,
  frictionAir: 0
});

Self-Collision Fix (Compound Body Parts)

Events.on(engine, "collisionStart", function (event) {
  event.pairs.forEach(function (pair) {
    var a = pair.bodyA.parent || pair.bodyA;
    var b = pair.bodyB.parent || pair.bodyB;

    // skip a pot colliding with its own internal decomposed parts
    if (a === b) return;

    var relSpeed = Vector.magnitude(Vector.sub(a.velocity, b.velocity));
    if (relSpeed >= IMPACT_THRESHOLD) spawnNote(/* ... */);
  });
});

Synthesized Sound (Web Audio API)

function playTone(frequency, duration, type, volume) {
  var ctx = getAudioContext();
  var osc = ctx.createOscillator();
  var gain = ctx.createGain();

  osc.type = type;
  osc.frequency.value = frequency;
  gain.gain.setValueAtTime(volume, ctx.currentTime);
  gain.gain.exponentialRampToValueAtTime(0.0001, ctx.currentTime + duration);

  osc.connect(gain);
  gain.connect(ctx.destination);
  osc.start();
  osc.stop(ctx.currentTime + duration);
}

Gyroscope-Driven Gravity

function handleOrientation(event) {
  var gamma = event.gamma || 0; // left-right tilt
  var beta = event.beta || 0;   // front-back tilt

  __activeEngine.world.gravity.x = Math.max(-1, Math.min(1, gamma * TILT_SENSITIVITY));
  __activeEngine.world.gravity.y = Math.max(0.2, Math.min(1.5, 1 + beta * TILT_SENSITIVITY * 0.3));
}

function requestOrientation() {
  if (typeof DeviceOrientationEvent.requestPermission === "function") {
    DeviceOrientationEvent.requestPermission().then(function (state) {
      if (state === "granted") {
        window.addEventListener("deviceorientation", handleOrientation, true);
      }
    });
  } else {
    window.addEventListener("deviceorientation", handleOrientation, true);
  }
}

Challenges & Solutions

Challenge: Collision Speed Always Read as Zero

Solution: Concave pot bodies get split into multiple convex parts internally by poly-decomp. Collision events were frequently firing between a pot's own internal parts, giving identical velocities and a relative speed of exactly zero. Fixed by resolving every collision pair to body.parent and skipping pairs where both sides resolved to the same body.

Challenge: Notes Couldn't Be Picked Up With the Mouse

Solution: MouseConstraint checks collision-filter compatibility before allowing a grab, not just body-body physics. The notes' restrictive filter (added so they'd ignore pots mid-fall) accidentally excluded the mouse's default category too. Fixed by explicitly including the default category bit in the notes' collision mask.

Challenge: Cradle Not Staying Centered on Resize

Solution: Pot positions were fixed at creation time and didn't move with the window. Solved by calculating the delta between the old and new center on resize and translating every pot body and string anchor by that same offset.

Challenge: Gyroscope Button Scope Errors

Solution: The tilt-request function was originally trapped inside the cradle's local function scope, so an HTML button's onclick couldn't reach it. Moved requestOrientation() and handleOrientation() to global scope, tracking the active physics engine via a module-level reference.

Challenge: Pots and Notes Too Small on Mobile

Solution: Fixed pixel sizes looked disproportionately small on narrow phone screens. Solved by scaling pot and note sizes relative to window.innerWidth, clamped within sensible min/max bounds.
